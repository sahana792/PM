# PM - Project Management System

A Java-based Project Management System developed using NetBeans, JSP, Servlets, and MySQL.

## Features
- Admin Dashboard
- Employee Management
- Project Tracking
- Task Assignment
- Progress Monitoring

## Technologies Used
- Java
- JSP & Servlets
- MySQL
- HTML/CSS
- NetBeans IDE
